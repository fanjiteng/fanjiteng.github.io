# C++中vector的简洁用法

`vector` 是 C++ 标准库中提供的一个动态数组类，它可以在运行时自动调整大小，方便地存储和管理一系列元素。以下是一些基本用法和示例：

### 1. 引入头文件
在使用 `vector` 之前，你需要包含头文件：
```cpp
#include <vector>
```

### 2. 创建一个 vector
```cpp
vector<int> vec; // 创建一个空的整型 vector
vector<int> vec2(10); // 创建一个包含 10 个默认值（0）的整型 vector
vector<int> vec3(5, 2); // 创建一个包含 5 个值为 2 的整型 vector
```

### 3. 添加元素
可以使用 `push_back` 方法向 `vector` 末尾添加元素：
```cpp
vec.push_back(1);
vec.push_back(2);
vec.push_back(3);
```

### 4. 访问元素
可以使用下标或 `at()` 方法访问元素：
```cpp
int first = vec[0]; // 访问第一个元素
int second = vec.at(1); // 访问第二个元素
```

### 5. 删除元素
使用 `pop_back` 删除最后一个元素：
```cpp
vec.pop_back(); // 删除最后一个元素
```

### 6. 遍历元素
使用范围 `for` 循环遍历 `vector` 中的元素：
```cpp
for (int num : vec) {
    std::cout << num << " ";
}
```

### 7. 获取大小
可以使用 `size()` 方法获取当前元素数量：
```cpp
std::cout << "Size: " << vec.size() << std::endl; // 输出当前元素数量
```

### 8. 清空 vector
使用 `clear()` 方法可以清空 `vector` 中的所有元素：
```cpp
vec.clear(); // 清空所有元素
```

### 9. 其他常用功能
- **容量与大小**：
  - `capacity()`：返回当前分配的内存大小。
- **检查是否为空**：
  - `empty()`：如果 `vector` 为空，返回 `true`。

### 示例代码
以下是一个完整的示例代码，演示了 `vector` 的基本用法：
```cpp
#include <iostream>
#include <vector>

int main() {
    vector<int> vec;

    // 添加元素
    vec.push_back(10);
    vec.push_back(20);
    vec.push_back(30);

    // 访问元素
    std::cout << "First element: " << vec[0] << std::endl;

    // 遍历元素
    std::cout << "Elements in vector: ";
    for (int num : vec) {
        std::cout << num << " ";
    }
    std::cout << std::endl;

    // 获取大小
    std::cout << "Size: " << vec.size() << std::endl;

    // 清空 vector
    vec.clear();
    std::cout << "Size after clear: " << vec.size() << std::endl;

    return 0;
}
```

这个例子创建了一个 `vector`，添加了一些元素，访问并打印它们的值，然后清空 `vector` 并打印新的大小。
